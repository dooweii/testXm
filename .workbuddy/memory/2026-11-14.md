- 在空目录 `D:/AAAxm/reactxm` 从零生成项目，用户要求「自动 npm」，已自动完成 install / build / dev 启动。
- 锁定版本（npm view 校验过）：react/react-dom 18.3.1、antd 6.7.0、@ant-design/icons 6.3.4、umi 4.7.32、typescript 5.9.3、dayjs 1.11.23、Node 22。
- 架构选择：用纯 `umi@4` + 自写 layout，**刻意不使用 @umijs/max / ProLayout**，避免它们附带 antd5 依赖与 antd6 冲突；依赖里自行声明 antd6 + icons6。
- 配置式路由 + `src/layouts/index.tsx` 全局布局，layout 用 `children ?? <Outlet />` 兼容渲染；ConfigProvider 提供 zhCN、亮/暗主题切换，antd `App` 提供 message 上下文，页面用 `App.useApp()`。
- 页面：首页 Dashboard（纯 SVG 趋势图、Statistic、Timeline）、用户管理（Table/Form/Modal/Popconfirm + 本地模拟服务 services/user.ts）、关于页（版本清单/命令/目录树/antd6 升级要点）。

### 踩坑记录（复用价值高）

1. Umi 4 配置校验严格，`.umirc.ts` 里写 `favicon` 会报 `Invalid config keys: favicon`，正确键是 `favicons: ['/favicon.svg']`。
2. Umi 4 分包构建后 esbuild 压缩 helper 变量名冲突，报 `Found conflicts in esbuild helpers`，必须配置 `esbuildMinifyIIFE: true`，否则 build 以 fatal 结束。
3. `mfsu: false` 用于规避 antd6 纯 CSS Variables 产物在预编译缓存中的样式问题。
